4.1 1. 决策主体与研究目标

维度 说明
报告受众 机构投资者、产业战略投资者、政策研究人员、拟参与科创板打新的个人/机构投资者
面临决策 长鑫科技拟科创板 IPO 募资约 295 亿元，尚无二级市场代码；需判断一级市场估值区间、上市后合理定价区间及产业链外溢影响
研究目标 基于网络下载的真实数据（招股书、行情、宏观、同业财务），刻画公司财务轨迹、行业可比估值水平，给出初步估值区间与后续分析框架

4.2 2. 政策/市场背景

4.2.1 2.1 核心政策与文件（公开信息摘要）

文件/政策 时间 关键内容
《新时期促进集成电路产业和软件产业高质量发展的若干政策》 2020-08 延续企业所得税优惠、研发加计扣除，强化产业链协同
《“十四五”国家信息化规划》 2021-12 强调集成电路全产业链突破，存储器为重点环节
《关于2025年加力扩围实施大规模设备更新和消费品以旧换新政策的通知》 2025-01 间接拉动电子终端需求，支撑存储周期
长鑫科技《首次公开发行股票并在科创板上市招股说明书（申报稿）》 2025-12-30 披露 2024 年营收 241.78 亿元、累计亏损、募资用途及产品结构

4.2.2 2.2 政策意图

  • 自主可控：降低 DRAM 对外依存度（2024 年中国集成电路进口仍超 3,500 亿美元量级，存储占进口结构重要份额）。
  • 资本支持科创板：允许未盈利、高研发投入的硬科技企业上市融资。

4.2.3 2.3 问题严重程度（数字来自招股书/公开报道）

  • 2024 年营收 241.78 亿元，同比 +166%（招股书合并利润表）。
  • 2022—2025 年 6 月累计营收 736.36 亿元，同期累计净亏损 408.57 亿元（申报稿摘要）。
  • 按出货量计，长鑫为中国第一、全球第四 DRAM 厂商（招股书引用 Omdia）。
  • 拟募资 295 亿元，为科创板历史最大 IPO 募资规模之一（交易所受理公告，2025-12-30）。

4.3 3. 数据下载（akshare + 上交所 PDF）

以下代码从网络拉取全部原始数据，保存至 data/ 子目录。

import os
import sys
from pathlib import Path

# 将项目根目录设为 DS
ROOT = Path.cwd()
if not (ROOT / "data").exists() and (ROOT.parent / "data").exists():
    ROOT = ROOT.parent
if str(ROOT) not in sys.path:
    sys.path.insert(0, str(ROOT / "scripts"))

os.chdir(ROOT)
sys.path.insert(0, str(ROOT / "scripts"))
from plot_style import setup_theme
setup_theme()
print("工作目录:", ROOT)
# 执行批量下载（约 3–8 分钟，取决于网络）
from download_data import main as download_main

download_main()
# 检查下载结果
from pathlib import Path
